# Security policy

OMP Guardian makes automated safety decisions, so security bugs are
taken seriously.

Do not file a public issue for a vulnerability. Use GitHub private vulnerability
reporting:

https://github.com/Warc0s/omp-guardian/security/advisories/new

Include, when possible:

- a minimal reproduction with synthetic data;
- the extension and OMP versions;
- the expected and actual decision;
- a redacted audit record;
- whether the deterministic route, model reviewer, or manual disposition ran.

Never submit credentials, real private paths, session files, cookies, or raw
private repository data. This extension is defense in depth and does not replace
OMP's approval system, provider safeguards, or operating-system isolation.
